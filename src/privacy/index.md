# Privacy policy

Last updated: February 10, 2026

This is my personal website. I want to be upfront about what happens when you visit.

## What I collect

Nothing. This site is a set of static files. There is no account, no form, no
newsletter, and no database. I don't collect personal information, email
addresses, or anything I could use to identify you.

## Analytics

There is no analytics on this site. I don't know which pages you visited or how
you got here. If I ever add analytics, this page changes first and a consent
prompt comes back with it.

## Cookies

The site sets no cookies. Your browser stores one preference locally — whether
you're using the light or dark version of the site — and that never leaves your
device.

## Search

Site search runs entirely in your browser against an index downloaded with the
page. Your search terms are never sent anywhere.

## Third-party services

The site is hosted on GitHub Pages. GitHub may collect technical information
(like IP addresses) as part of serving the site. See
[GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
for details.

Some pages link out to other sites. Once you follow a link, that site's own
privacy policy applies.
